# Authentication Pages (`/login` & `/signup`)

## Description
Clean, secure developer sign in and registration interface to get an API key.

## Sections
- Minimal Brand Header
- Auth Card (Sign In / Sign Up Form)
- Social OAuth Buttons (GitHub, Google)
- Email & Password Inputs
- Form Validation & Security Note
- Mode Switcher Link (Sign In ↔ Sign Up)
- Minimal Footer
